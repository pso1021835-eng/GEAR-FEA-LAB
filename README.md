# GEAR-FEA-LAB

기어·감속기 부품 강도 시뮬레이션을 브라우저에서 수행하기 위한 선형 유한요소 해석 실험 저장소입니다.

## 목적

- 기어 형상과 하중 조건을 입력해 선형 탄성 응력 해석을 수행합니다.
- 3D 시각화와 응력·안전율 결과를 비교할 수 있는 인터페이스를 목표로 합니다.
- 장기적으로 기어뿐 아니라 감속기 부품의 공학적 추정 도구로 확장합니다.

## 한계

- 선형 탄성, 소변형 범위의 공학적 추정입니다.
- 치면 접촉 FEA, 소성 변형, 균열 진전, 동적 파동, 잔류응력 및 경화층을 포함하지 않습니다.
- 결과는 시험 성적서와 부품 검증을 대체하지 않습니다.
- 실제 부품 제조 전에는 인증된 해석 절차와 독립 검증이 필요합니다.

## F2 해석 및 확인

HTTP로 페이지를 열고 원형 보어가 있는 외접 스퍼 기어를 설정합니다. 키홈 폭과 웨브 구멍 수를 0으로 두고 맞물림 기어 잇수와 양의 토크를 입력한 후 **해석 실행**을 누릅니다. 화면에는 5치 섹터의 중앙폭 치근 최대주응력과 요소 중심 최대 von Mises 응력이 표시됩니다. 섹터 절단면은 자유이고 보어는 고정입니다. 균일 치폭 하중에서는 중앙면 대칭으로 반폭만 계산합니다.

`node tests/run_all.js`는 외팔보, 단축 인장 패치, 기어 HPSTC 하중과 반력 평형을 확인합니다. `node tests/gear_convergence.js`는 기어 메시와 경계 민감도를 비교하고 기준에 미달하면 종료 코드 1을 반환합니다.

`node --max-old-space-size=6144 tests/gear_convergence.js --3d --mesh-only`는 7치 기준에서 반경층, 필렛·플랭크 분할, 치폭층을 함께 늘린 3수준을 계산합니다. `--mesh-only`를 빼면 필렛 크기 목표를 만족하는 첫 수준에서 5·7·9치 및 절단면 고정 민감도도 계산합니다. 이 정밀 검증은 브라우저 예비 모델보다 시간·메모리를 더 사용합니다.

초기 사례 C의 5치 섹터에서 3수준 치근 응력은 약 91.43, 92.78, 124.99 MPa였고 패치 하중가중 변위는 0.002989, 0.002976, 0.003614 mm였습니다. 두 세밀 수준 사이의 응력과 변위 변화는 각각 약 26%, 18%로 목표 3%, 2%를 초과했습니다. 5→7치의 하중가중 변위 변화도 약 10%였습니다. 당시 최종 메시의 97,461 자유도 해석은 로컬 Node에서 약 46초 걸렸습니다. 현재 비교 스크립트는 중앙폭 HPSTC 점의 변위를 판정에 사용하고 하중가중 변위도 함께 출력합니다. 화면 수치는 예비 결과입니다.

곡률에 맞춰 윤곽을 추가 분할한 7치 정밀 모델은 3수준에서 145.903, 145.484, 146.325 MPa 및 0.00427563, 0.00425548, 0.00427016 mm로 수렴했습니다. 마지막 변화는 응력 0.58%, 변위 0.34%이며 피크는 같은 필렛에 남았습니다. 첫 정밀 수준의 5→7치 변위 차이는 5.72%, 7→9치 차이는 3.59%였습니다. 7치 절단면을 고정하면 변위가 6.74% 달라 경계 민감으로 분류합니다. 가장 세밀한 정밀 모델은 410,826 자유도였고 로컬 Node에서 약 197초 걸렸습니다.

메시 API는 전체 기어의 원형 보어와 키홈 면을 따로 식별합니다. 키홈 접촉·구속과 웨브 구멍 해석은 현재 지원 범위 밖입니다.

로컬 Node 성능 시험에서 34,263 자유도는 6.1초, 80,388 자유도는 17.8초였습니다. 80,388 자유도에서 선형계 풀이가 15.9초를 차지해 3만~10만 자유도 범위 전체의 성능 목표는 아직 확인되지 않았습니다.

- `docs/` — 설계 기준, 검증 계획 및 기록
