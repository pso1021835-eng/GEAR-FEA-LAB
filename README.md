# GEAR-FEA-LAB

기어·감속기 부품 강도 시뮬레이션을 브라우저에서 수행하기 위한 선형 유한요소 해석 실험 저장소입니다.

## 목적

- 기어 형상과 하중 조건을 입력해 선형 탄성 응력 해석을 수행합니다.
- 3D 시각화와 응력·안전율 결과를 비교할 수 있는 인터페이스를 목표로 합니다.
- 장기적으로 기어뿐 아니라 감속기 부품의 공학적 추정 도구로 확장합니다.

## 한계

- 선형 탄성, 소변형 범위의 공학적 추정입니다.
- 치면 접촉 FEA, 소성 변형, 균열 진전, 동적 파동, 잔류응력 및 경화층을 포함하지 않습니다.
- 결과는 시험 성적서와 부품 검증을 대체하지 않습니다.
- 실제 부품 제조 전에는 인증된 해석 절차와 독립 검증이 필요합니다.

## 폴더 구조

- `src/` — 브라우저 해석 및 시각화 소스
- `tests/` — 문법 및 계산 회귀 테스트
- `docs/` — 설계 기준, 검증 계획 및 기록
